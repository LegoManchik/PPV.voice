1. Установить Python 3.12
2. Установить все библиотеки:
```
pip intall requirements.txt
```
3. Создать `.env` в папке `discord_bot`
   ```
   .env
   DS_TOKEB=токен_дискорд_бота
   TG_TOKEN=токен_телеграмм_бота
   ```
4. `data/ping_users.json` добавить в список ID пользователей которых бот будет пинговать в тикете при заявке
5. Запустить `bot.py`
